# Django - 1 - Base Django

First Django day of the **42 Django Piscine**. One project (`d05`) with each
exercise as its own app: views and URL routing, templates and static files, a
model with a form saving to the database, and template inheritance.

Exercises `ex00` → `ex03`. Run with `docker compose up --build`.

Deployed at **https://base-django.pulgamecanica.com/**
